# Milestone 11 learnings

- Structural conformance compares proof identity and state, not identical
  provider features or outcomes.
- A missing provider usage field must remain unknown; substituting zero creates
  false cost and performance comparisons.
- Existing adapter boundaries already normalize enough lifecycle behavior for
  a shared proof matrix without changing the wire protocol.
- Synthetic topology fixtures catch contract drift early, but live account,
  scheduling, persistence, and hosting receipts must remain separate gates.

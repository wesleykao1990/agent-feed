# Milestone 6 bug and gap log

Started: 2026-08-18. This log is append-only.

| ID | Symptom / impact | Resolution and regression | Status |
|---|---|---|---|
| M6-001 | The MCP SDK's modern HTTP entry rejected otherwise valid messages when SEP-2243 `Mcp-Method` (and tool-call `Mcp-Name`) headers were absent. | Make the conformance client send the standard headers and retain the official SDK's fail-closed cross-check. | Resolved; modern HTTP list/call regressions. |
| M6-002 | A generic exception from a test verifier mapped to a server error rather than a bounded OAuth `invalid_token` challenge. | Require verifier implementations to throw the SDK-branded `OAuthError`; production verifiers already do so. | Resolved; bad-token 401 regression. |
| M6-003 | Node's strip-only TypeScript execution rejected a constructor parameter property even though `tsc` accepted it. | Replace the parameter property with an explicit field assignment. | Resolved; direct Node test execution. |
| M6-004 | TypeScript's `BodyInit` declarations did not accept Node's `Uint8Array<ArrayBufferLike>` shape under strict exact optionals. | Keep the runtime-safe byte body and narrow only the Node-to-web adapter cast. | Resolved; strict build. |
| M6-005 | The first live durability assertion assumed begin metadata would be merged into the terminal envelope, but completion owns the terminal envelope metadata. | Assert durable producer/stream identity, terminal state, finding, and evidence instead of inventing cross-phase metadata merge semantics. | Resolved; live PostgreSQL regression. |
| M6-006 | The available Claude session is a Team/Enterprise member workspace and does not expose Organization settings, so it cannot register a custom connector. | Keep the tested HTTPS/OAuth service running for handoff; require an Owner/Primary Owner or an individual Pro/Max account before recording the Claude receipt. | External account-access blocker; not a gateway defect. |
| M6-007 | The pre-M7 combined local gate initially invoked Homebrew system Python, which could not see the already approved repository dependencies; sandboxed Node runs also could not bind/connect to localhost. | Run Python validation and wheel construction with the repository `.venv` first on `PATH`, and rerun listener/PostgreSQL gates with explicit localhost permission. | Resolved; full M0-M6 local regression green. |
| M6-008 | The first PR #8 M6 job installed only the two MCP apps. On a clean runner, source-linked `producer-service` could not resolve `@agent-feed/schema`, and the build/tests failed before assertions ran. | Install every source-linked package in the M6 dependency chain before the apps, and make the architecture guard require the complete clean-install list. | Resolved locally; hosted rerun required. |
| M6-009 | After the source-link installs were added, the second PR #8 run resolved `@agent-feed/schema` but its generated `dist/index.js` did not exist on the clean checkout. | Make `m6:conformance` build the schema package before either MCP app and require that step in the architecture guard. | Resolved locally; hosted rerun required. |
